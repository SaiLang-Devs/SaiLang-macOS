About SaiLang

SaiLang is a general-purpose programming language with English-like commands. It is made for people who are new to coding, and for experienced developers who want something small and readable for scripts, simple desktop apps, and games.

What SaiLang is for

  • Learning. Every line says what it does. There are no symbols to memorise beyond a few basic operators.
  • Small tools. Read a file, count words, sort a list, or ask the user questions.
  • Desktop windows. Open a window, add labels, buttons and text boxes, and show PNG or GIF pictures.
  • Simple games. Draw shapes, read the arrow keys, run a game loop, and detect collisions.

The language at a glance

make ages = [9, 10, 11]

for each age in ages {
    when age >= 10 {
        say age, "is old enough for the club"
    } otherwise {
        say age, "is too young for the club"
    }
}

command double(n) {
    give n * 2
}
say "Double 7 is", double(7)

Main features in version 1.0:

  • Numbers, text, true/false values, lists, and nothing
  • when / otherwise, repeat, while, for each, stop and skip
  • Commands with inputs and results, including recursion
  • try / on error, and error messages that name the file and line
  • import to reuse code from another file
  • A standard library for text, lists, maths, files and user input
  • SaiLang IDLE, an editor with colours and a Run button

Honest limits of version 1.0

  • SaiLang runs programs through a Python engine. It does not yet make standalone .exe files.
  • Pictures must be PNG or GIF.
  • There are no classes or dictionaries yet.
  • Windows and games need Python's "tcl/tk" option, which the Python installer offers.

Project

SaiLang 1.0.0 is released under the MIT licence, which means you may use, change and share it freely. The language rules are written down in the language specification included in the download. Anyone can report bugs or suggest changes on the project's source repository.
