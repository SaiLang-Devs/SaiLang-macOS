Readable by design

Write what you mean. Variables are made with make, output uses say, and decisions are made with when and otherwise.

SaiLang runs on Windows 10 and 11 and works without administrator rights.

make player = "Sai"
make score = 0

command greet(name) {
    say "Hello,", name
}

greet(player)

repeat 5 times {
    make score = score + 10
}

when score >= 50 {
    say "Level complete!"
} otherwise {
    say "Keep playing!"
}

Good to know

SaiLang 1.0 runs programs through a Python engine, so Python 3.9 or newer must be installed. Installing Python from python.org takes a few minutes and does not need administrator rights. Compiling to a standalone program is planned for a later version.
